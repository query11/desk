# Desk 测试清单

每个版本都在你的电脑上按这个清单检查一遍。发现问题时，请带上：

- 截图；
- 日志文件夹里的文件（设置窗口 → 设置 →「日志」，即 `%LOCALAPPDATA%\Desk\logs`）；
- 当时做了什么操作。

## 0. 准备

- [ ] 关掉其他会修改任务栏的工具，例如 Windhawk 的任务栏样式模组、TranslucentTB、StartAllBack、RoundedTB。
- [ ] 确认「设置 → 个性化 → 颜色 → 透明效果」是打开的。关闭时 Desk 会退回纯色背景，这是预期行为。
- [ ] 从 Actions 下载最新的 `Desk-…` 压缩包，解压到一个固定的文件夹，比如 `D:\Tools\Desk`。
  开机自启记录的是这个位置，以后换文件夹的话，在新位置运行一次 `Desk.exe` 就会自动更新。
- [ ] **从 v0.1 升级时**：先在旧版托盘菜单里「退出并还原」，再用新文件覆盖。

## 1. 启动和窗口

- [ ] 双击 `Desk.exe`：几秒内任务栏变成浮岛，同时打开 Desk 的设置窗口（Mica 背景，左侧导航）。
- [ ] 如果资源管理器里还在跑 v0.1 的引擎，概览页会提示「Desk 已更新」。点「重启资源管理器」后提示消失。
- [ ] 关闭窗口：Desk 留在托盘里，第一次关闭时弹出「Desk 仍在后台运行」的提示。
- [ ] 单击托盘图标、或者再次双击 `Desk.exe`，都会重新打开窗口，并且只有一个 Desk 在运行。
- [ ] 概览页：任务栏和开始菜单的状态显示「已生效」（开始菜单在第一次打开前可能显示「下次打开开始菜单时生效」）。

## 2. 浮岛外观（对照图一）

- [ ] 应用岛居中，托盘岛在右侧，左侧是信息岛，岛之间露出壁纸。
- [ ] 信息岛每秒刷新：上传/下载速度（下载文件时数字明显变大）、CPU 和内存占用；占用超过 85% 时数字变红。
- [ ] 「任务栏」页 → 左侧信息岛：关掉开关后信息岛消失，取消勾选某一项后对应的内容消失。
- [ ] 系统的小组件（天气）按钮不再跑到应用岛外面（信息岛打开时它是隐藏的，Win + W 仍能打开小组件）。
- [ ] 岛是亮的亚克力质感：能透出壁纸的颜色，近看有细微颗粒，顶部有一道亮边，不再发灰发闷。
- [ ] 「任务栏」页的每个滑块都有图标、名称和说明（圆角、上下留白、模糊、着色浓度、明暗统一、饱和度、颗粒感），拖动时任务栏实时跟着变化。
- [ ] 「恢复默认」能回到主题原来的样子。
- [ ] 换一张很亮和一张很暗的壁纸，岛上的文字和图标都看得清。

## 3. 开始菜单（对照图二）

- [ ] 打开开始菜单：背景是**模糊**的毛玻璃。后面窗口里的文字看不清，只透出颜色和大致轮廓（如果还能看清后面的文字，说明模糊没生效，请截图并附上日志）。
- [ ] 「开始菜单」页 → 配色：切到「深色玻璃」后打开开始菜单，文字变成白色、背景是深色毛玻璃；切到「浅色玻璃」「跟随 Windows 模式」也跟着变化。
- [ ] 拖动玻璃效果的滑块后再打开开始菜单，效果跟着变化。
- [ ] 搜索、固定项、全部应用、电源按钮、右键菜单、手机连接侧栏都正常。
- [ ] 深色玻璃下，没有看不清的黑色文字（如果有，请截图标出位置）。

## 4. 原生功能（逐项确认都正常）

- [ ] 点击、右键任务栏图标；跳转列表能正常打开。
- [ ] 把文件拖到任务栏图标上，能切换到对应窗口。
- [ ] 托盘：`^` 溢出区、OneDrive、`中`/`英` 切换、Wi-Fi、音量、电池的弹窗都正常。
- [ ] 时钟和日历、通知中心（`Win + N`）、快速设置（`Win + A`）都正常。
- [ ] 全屏播放视频或玩游戏时，任务栏不会跳出来。

## 5. 窗口最大化

- [ ] 默认模式「恢复成整条任务栏」：最大化一个窗口后，任务栏恢复成原生的整条；还原窗口后又变回浮岛。
- [ ] 「任务栏」页 → 窗口最大化时 → 自动隐藏任务栏：最大化时任务栏自动隐藏，还原窗口后恢复显示。
- [ ] 改成「保持浮岛」后，最大化时也保持浮岛。

## 6. 开机自启和速度

- [ ] 「设置」页的「开机自动启动」默认是打开的。
- [ ] 重启电脑并登录：Desk 不弹出窗口，只在托盘出现；任务栏在桌面出现后很快变成浮岛。
  可以在日志里找 `Taskbar engine loaded … ms after start` 这一行，看从 Desk 启动到任务栏生效用了多久。
- [ ] 关闭「开机自动启动」后重启电脑，Desk 不再自动运行；再打开又会恢复。
- [ ] （可选）在「任务计划程序」里能看到 `Desk Autostart (你的用户名)` 这个任务。

## 7. 主题和其他设置

- [ ] 概览页切换主题「Desk 浮岛 · 高通透」「Desk 整条毛玻璃」，都能立即生效。
- [ ] 在系统设置里切换浅色/深色模式，任务栏的岛跟着变化；设置窗口也跟着变成浅色/深色。
- [ ] 打开「空白处点击穿透（实验）」后，点岛之间的空白处能点到下面的桌面或窗口；岛本身仍然正常。关闭后恢复原样。
- [ ] 「设置」页 →「主题文件夹」会生成 `my-theme.json`，修改并保存后，在主题列表里选它能生效。

## 8. 稳定性和还原

- [ ] 按 `Ctrl + Alt + Shift + D`：任务栏和开始菜单立即恢复原样；再按一次，美化回来。
- [ ] 「重启资源管理器」后，美化在几秒内自动恢复。
- [ ] 托盘菜单或「设置」页的「退出并还原」：任务栏和开始菜单恢复成系统原样，托盘图标消失。
- [ ] 正常使用半天：资源管理器的内存没有持续上涨，也没有崩溃或卡顿。

## 已知限制（v0.3）

- 只支持 x64 的 Windows 11 24H2/25H2；任务栏放在顶部或左右两侧时还没有适配。
- 带 `@状态` 的样式（悬停、按下等视觉状态）暂不支持，导入 Windhawk 主题时这类规则会被跳过。
- 多显示器时，「窗口最大化」只看主任务栏所在的显示器。
- 从旧版本升级后，资源管理器需要重启一次才会换上新的引擎。
- 任务栏靠左对齐时，窗口最大化后（恢复成整条任务栏）不显示信息岛，以免挡住开始按钮。
