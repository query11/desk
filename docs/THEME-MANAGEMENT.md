# Desk 0.6.0：预览、试用和个人方案

## 六项改进

1. **用自己的壁纸比较效果**：外观方案页和概览都用当前壁纸预览；外观方案页的“我的壁纸”开关可随时切回示例壁纸。壁纸读不到时自动使用示例，手动打开开关时会说明原因。预览是材质与布局示意，实际效果仍以 Windows 桌面为准。
2. **试用 15 秒**：方案卡片点击“试用 15 秒”，窗口顶部显示倒计时和进度条；选择“保留这套”确认，或“立即还原”。试用期间，卡片上也可以直接“保留这套”，原方案的卡片显示“还原到这套”。到时自动回到试用前方案。关闭设置窗口也会计时，退出或异常中断后重启会恢复原方案。
3. **管理个人方案**：点方案名称旁的星标收藏、按收藏筛选；“⋯”菜单中复制、重命名、导出或删除，顶部可导入 JSON。菜单只列出对该方案可用的操作，内置方案可先复制再修改名称。导入使用新身份，不覆盖已有主题；导出包含该主题的微调。删除的个人主题移至主题目录的 `.trash`，可重新导入恢复。
4. **查看微调记录**：改过参数的方案标有“已微调”，“⋯ → 查看微调记录”显示相对默认值的变化、浅深色范围，可逐项还原。该列表是当前差异，不是持久化的时间线；“撤销调整”保存本次运行期间的有限操作历史。
5. **按显示器调整**：左下方“显示器”页面选择屏幕，打开独立设置，可设置图标大小、间距、材质、信息岛内容和窗口最大化时的整条/浮岛行为。信息岛及其各项内容、最大化行为都可选“跟随全局”或单独指定。关闭独立设置即跟随全局，已有参数保留。显示器拔掉后配置仍保留，以设备标识匹配。
6. **更多成套预设**：增加紧凑办公、圆润胶囊、极简透明。推荐列表共 7 套，“全部”另保留 3 套经典方案。

| 新方案 | 图标 / 按钮宽度 | 任务栏风格 | 开始菜单 |
| --- | --- | --- | --- |
| 紧凑办公 | 26 / 44 px | 8 px 圆角、较高遮盖度 | 12 px 圆角，清晰易读 |
| 圆润胶囊 | 28 / 50 px | 24 px 圆角、柔和玻璃 | 28 px 圆角，柔和材质 |
| 极简透明 | 28 / 46 px | 3 px 圆角、低浓度透明 | 10 px 圆角，轻量材质 |

这些是主题的逻辑像素默认值，Windows 缩放及单独微调会影响实际尺寸。升级不会自动切换主题或覆盖图标大小。

## 界面细节（0.6.0 之后的改进，不涉及原生引擎）

- **外观方案**：分类按钮显示各自的方案数量；切换方案后出现“撤销切换”。分类、搜索词、预览配色、壁纸开关和“撤销切换”在设置窗口打开期间一直保留，去概览看完状态再回来不会丢。预览配色默认跟随 Windows，手动切换后保持所选。
- **概览**：预览按实际设置画出左侧信息岛（空间不够时减少项目）；美化停用时预览变淡。资源管理器仍在运行旧版引擎时，提示里直接提供“重启资源管理器…”。任务栏或开始菜单出现问题时，“维护与恢复”自动展开。
- **开始菜单**：关闭“美化开始菜单”后，配色和玻璃效果一并停用并说明原因。
- **任务栏 / 开始菜单 / 显示器**：“效果预览”“高级设置”保持上次展开或折叠的状态。
- **显示器**：与其他页面相同的卡片布局；顶部说明已连接几块屏幕、几块在使用独立设置。
- **窗口**：初始大小不超过屏幕工作区，1366 × 768 的屏幕上也能完整显示。

## 范围与兼容性

- 沿用 .NET 10、WPF、WPF-UI 4.3.0，没有新增运行时依赖。
- 开始菜单沿用全局方案，Windows 自动隐藏仍为全局开关。每屏独立行为是最大化时合并或保持浮岛。
- 当前壁纸预览使用系统当前壁纸文件，不模拟多屏分别设置壁纸、动态视频壁纸或真实 Windows 控件截图。
- 保留开始菜单 `BackdropSource="Backdrop"`。自适应逻辑不修改 TaskbarFrame 的 Margin 或 MaxWidth，避免再次将应用挤入省略号。
- 本次更新了 DeskTap 原生 DLL，已经加载旧 DLL 的 Explorer 和开始菜单进程需要重新加载。保留旧目录便于回退。
- 用户设置位于 `%APPDATA%\Desk\settings.json`，个人主题位于 `%APPDATA%\Desk\themes`，运行日志位于 `%LOCALAPPDATA%\Desk\logs`。

## 开发验证

- 140 项 .NET 测试通过：试用超时/重启恢复/连续试用/保存失败恢复，个人主题生命周期，独立显示器参数与最大化行为，现有主题和恢复逻辑。
- 21 组 WPF 场景通过：8 组参数页、4 组图库、4 组整窗、4 组显示器页、1 组当前壁纸预览。覆盖浅深色、宽窄布局、收藏、试用入口、错误/空状态和倒计时栏布局。
- 原生引擎：31 项核心测试、4 项真实 Composition 材质测试，以及 1 组生产配置解析检查通过；验证各屏规则独立、缓存标识不重复、宿主失联恢复及未知窗口回退。
- .NET 和原生版本均为 0.6.0；界面渲染证据位于 `build/ui-0.6.0`。
- 本机只有一块物理屏幕，多屏隔离通过模拟和配置测试；尚未完成真实双屏热插拔及不同缩放组合验证。
- 交互检查使用隔离 WPF 测试，实机引擎验收使用进程、配置、状态和日志；CI 另外运行完整窗口的 UI 冒烟测试。

## 本地更新与回退

### 圆角屏外观修正（2026-11-10）

“通透浮岛”任务栏改用均匀的浅色细描边，减轻顶部高亮、底部暗边造成的轮廓差异。任务栏底部与两侧外缘默认留白均为 4 个逻辑像素，圆角为 10 个逻辑像素。这是按实机观感设置的值，并非读取到的屏幕硬件圆角半径。相关参数仍可在任务栏页调整；图标默认 28 px，升级保留用户已选尺寸，没有增加任务栏外框宽度限制。

### 安装与备份

从仓库 Actions 下载最新成功构建的 `Desk-…` 附件，解压到固定目录。更新前备份 `%APPDATA%\Desk`，在旧版托盘菜单选择退出并还原，再启动新版本并启用美化。原生 DLL 更新时按程序提示重新加载系统界面进程；保留旧安装目录便于回退。

2026-11-10 单屏实机验收：宿主及两个原生引擎均为 0.6.0，任务栏和开始菜单报告 `ready / applied`，配置序号与应用序号一致；样式错误、材质回退、材质失败均为 0。日志确认按显示器选择配置，溢出标记为 0；升级保留已有设置，圆角屏修正后再次确认样式生效。

如需回退，先从托盘退出 Desk，重新加载 Explorer 和开始菜单进程，再运行旧版本。旧版本不支持本次新增的个人收藏和显示器配置；回退前应另存当前设置文件。
